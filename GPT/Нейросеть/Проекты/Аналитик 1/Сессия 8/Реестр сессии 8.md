Важнейшие архитектурные положения:


1. GitHub Actions runner является вычислителем, но не постоянным хранилищем.
2. Снимки данных должны храниться в долговременном облачном хранилище.
3. SnapshotRef, Content Hash и provenance должны сохранять непрерывность на всём пути запроса.
4. Нельзя незаметно переключаться на новейший снимок при несовпадении версий.
5. Local MCP остаётся историческим направлением, но не является текущим пользовательским cloud-интерфейсом.


Отчёт A1 по этому направлению принят координатором. PR #107 объединён в `main`.
