# E2 lexical search benchmark — baseline result

**Status:** benchmark harness implemented; baseline numbers will be recorded from the dedicated GitHub Actions run on this PR head.

## Intended measurement

The synthetic-only corpus evaluates Russian inflection, exact phrase and near-miss ranking, rare-term retrieval, typo tolerance as a non-gating diagnostic, mixed lexical + exact-number queries, OR fallback, stable tie-break order, duplicate suppression, noise-only and empty-query behavior.

## Isolation

- No production search code or public API is changed.
- No production workflow is changed; only the dedicated benchmark workflow is added.
- No E1 SQLite, E3 Context Builder, token budget or Vault data is used.
- The index is an in-memory SQLite FTS5 instance and is closed after the run.
- All fixtures use synthetic source paths and benchmark-only Node IDs.

The final commit SHA, GitHub Actions run, artifact digest and measured metrics will be added after the first complete CI execution.
