## 4. Findings and limitations

1. **Phrase precision is not strict.** Query `точный сигнал` returns the contiguous phrase target first, but also returns a near-miss document containing the same terms in another order. Both are tier 4 / `exact_word_or_number`; the target wins on BM25. This benchmark makes that false positive visible rather than claiming strict phrase semantics.
2. **OR fallback broadens the result set.** Query `заснеженный маяк` returns the intended partial match and one additional document that contains the shared word `маяк`. The intended result remains first.
3. **Typo tolerance is absent in the current contract.** The one-character typo returns no result. This is a diagnostic observation, not a failed gate and not a request to add fuzzy search in this PR.
4. **Tie-break behavior is deterministic.** Equal synthetic records are ordered by source path and remain stable over five executions.
5. **Empty and noisy inputs remain distinct.** Punctuation-only input returns `not_found_in_retrieval`; an empty query without entity filters raises `ValueError`.

Potential improvements to phrase precision and OR-fallback precision are documented as future candidates only. No ranking weights or runtime behavior were changed.

## 5. Scope and safety

- All 12 records and all 9 queries are synthetic.
- No real Vault fragments, document names or source paths are used.
- No E1 SQLite, E3 Context Builder, token budget or production Vault was read or modified.
- The benchmark uses a disposable in-memory SQLite FTS5 index, closed after the run.
- No production search code, public API or production workflow was changed.
- A separate benchmark-only workflow was added with `permissions: contents: read`; it installs the existing E2 package and uploads JSON/Markdown evidence.
- The single initial CI failure was a harness-only field-name mismatch (`created` vs the actual `imported` result from E2 import). It was corrected before the final successful runs; no search implementation change was needed.

```bash
python -m pip install -e "GPT/Нейросеть/Проекты/Исполнитель 2/Сессия 1/Реализация/source[dev]"

  --repeats 5 --expected-engine pymorphy3 \

  --output-md /tmp/e2-lexical-benchmark.md

```
