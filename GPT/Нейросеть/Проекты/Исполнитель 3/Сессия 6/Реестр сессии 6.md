## 4. Что нельзя нарушать


Из Governance Protocol v2.4:


1. GitHub Issue является источником истины по задаче.
2. Самостоятельно захватывать можно только свободные задачи своей роли.
3. Обязателен цикл E → A → E.
4. Изменения панели выполняются через PR.
5. Никаких production-операций без соответствующего разрешения.


Технические ограничения:


- Только локальный stdio.
- Только read-only инструменты.
- Никаких GitHub API writes из MCP.
- Никаких HTTP/SSE/WebSocket.
- Никакого production indexing ради тестов.
- Никакого обхода SnapshotRef и verifier.
- Никакого хранения межвызовного состояния диалога на сервере.
