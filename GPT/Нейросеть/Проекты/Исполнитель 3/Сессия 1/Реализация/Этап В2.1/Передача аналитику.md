## Поведение, которое нужно проверить

1. SearchVaultService передаёт B1 SearchRequest и typed E3 SourceReadRequest в существующий ContextIntegrationPipeline и возвращает тот же ContextIntegrationResult без потери diagnostics/coverage/Included/Deferred/budget status.
2. ReadSourceService поддерживает node / parent / neighbors / document через существующий SourceReader.
3. Snapshot mismatch отклоняется до вызова SourceReader; mismatch snapshot echo отклоняется после вызова.
4. stale_source / ambiguous / deleted / not_found / integrity_error / budget_exceeded остаются бизнес-статусами и не маскируются под success.
5. Любой non-ok результат с fragments отклоняется как partial_error_payload.
6. Token accounting остаётся E3-owned; V2.1 не делает hashing, truncation или повторный подсчёт токенов.
7. В package exports доступны typed requests/results/protocols/errors.
8. Runtime package не добавляет GitHub, HTTP server или MCP dependencies.
