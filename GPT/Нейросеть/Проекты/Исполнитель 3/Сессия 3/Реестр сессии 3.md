Главные технические правила:


1. E2 выполняет поиск, но его `excerpt` не является оригинальным источником.
2. Оригинальный текст получает E3 через публичный API E1.
3. Все операции используют единый закреплённый `SnapshotRef`.
4. Контроль токенного бюджета принадлежит E3.
5. Никакого самостоятельного SQL-доступа к внутренней базе E1.
6. Никакого fuzzy matching или подмены устаревших адресов.
7. Никакого усечения исходных фрагментов.


Поддерживаются четыре режима чтения: `node`, `parent`, `neighbors`, `document`.
