После каждого своего ответа пользователю синхронизируй переписку с текущим проектом:

1. Работай только в каталоге текущего проекта.
2. Найди папку сессии с наибольшим числовым номером в названии «Сессия N». Работай с ней.
3. По истории Git определи дату и время последнего коммита, который изменял файл «Реестр Сессии.md» этой сессии.
4. Добавь в конец этого файла все сообщения текущего диалога, отправленные после указанного коммита: сообщения пользователя и свои ответы. Сохраняй полный текст и форматирование, явно указывай автора и соблюдай хронологический порядок.
5. Перед записью прочитай текущее содержимое «Реестра Сессии.md» и сохрани его дословно. Новую версию файла формируй только как исходное содержимое без каких-либо изменений плюс новые сообщения в конце. Запрещено создавать реестр заново, заменять, удалять, исправлять, сокращать, переформулировать, форматировать заново или перемещать уже имеющееся содержимое. Если инструмент требует передать полный текст файла, передавай прежнее содержимое неизменным и добавляй новые сообщения только после него. Перед сохранением проверь, что исходное содержимое полностью сохранено без изменений.
6. Зафиксируй обновлённый «Реестр Сессии.md» отдельным Git-коммитом. Другие файлы не изменяй.

Если папка последней сессии или файл реестра отсутствуют, не создавай их самостоятельно: сообщи об этом пользователю.
