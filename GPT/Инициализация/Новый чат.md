# Новый чат

**Назначение:** определить режим работы при начале диалога и не загружать лишний контекст.

## Алгоритм

1. Проверить доступность GitHub и актуальность файлов только если для этого есть действующий инструмент.
2. Определить намерение пользователя по текущему сообщению и доступному контексту.
3. Выбрать один режим:
   - `NORMAL` — обычная работа в текущем диалоге;
   - `CREATE` — создание нового проекта или контекста с сохранением;
   - `RESUME` — восстановление ранее начатого проекта или сессии по явной команде.
4. Не запускать `CREATE` или `RESUME` по одному лишь упоминанию проекта, если намерение неясно.
5. При неоднозначности задать один конкретный уточняющий вопрос.

## Режим NORMAL

- Работать с текущим запросом и контекстом диалога.
- Не читать автоматически реестр проектов, Промпт0 или проектные файлы.
- Не создавать записи и не заявлять о сохранении без реального инструмента и подтверждения.

## Ограничения

Файлы этой системы задают порядок действий, но не создают технический доступ к GitHub, другим чатам, памяти или внешним приложениям.
