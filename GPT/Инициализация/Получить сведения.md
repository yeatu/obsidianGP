# Получить сведения

По команде «Получить сведения» сообщи, какие компоненты контекста применены, используя **исключительно контекстную память текущего диалога**.

## 1. Если в контекстной памяти указан текущий проект

- Сформируй прямую ссылку на файл «Актуальный промпт.md» в корне текущего проекта на GitHub.
- Используй известное из контекстной памяти точное название проекта и сформируй путь в репозитории `yeatu/obsidianGP`, ветка `main`. Корректно URL-кодируй название проекта.
- Не открывай, не читай и не анализируй сам файл. Не обращайся к GitHub для проверки или получения его содержимого.
- В этом случае выведи ссылку на актуальный промпт проекта и не перечисляй отдельные компоненты по его содержимому.

## 2. Если в контекстной памяти явно указано, что текущий проект не выбран

Перечисли применённые компоненты, сведения о которых присутствуют в контекстной памяти:

- промпт личности;
- функциональный промпт;
- дополнительные инструкции.

Для каждого компонента укажи название и прямую ссылку на его исходный файл в GitHub, если точный путь известен из контекстной памяти. Ссылки формируй для репозитория `yeatu/obsidianGP`, ветка `main`.

Учитывай только компоненты, выбор и применение которых зафиксированы в контекстной памяти. Само наличие файла или упоминание его названия не подтверждает, что компонент применён.

## 3. Ограничения источника сведений

- Используй только контекстную память текущего диалога: сведения об установленном проекте и о выбранных и применённых компонентах.
- Не просматривай репозиторий, каталоги, файлы, историю Git или другие источники для выяснения того, что применено.
- Не открывай исходные промпты и файл «Актуальный промпт.md».
- Не восстанавливай недостающие сведения догадками.
- Если контекстная память не позволяет достоверно определить текущий проект или применённый компонент, прямо укажи, что эти сведения не определяются по доступной контекстной памяти. Не трактуй отсутствие сведений как доказательство того, что проект или компонент не применён.

## 4. Неизменность файлов

Выполнение команды носит информационный характер. Не изменяй «Актуальный промпт.md», исходные промпты, инструкции или любые другие файлы.
