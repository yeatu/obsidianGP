# Получить сведения

По команде «Получить сведения» сообщи, какие компоненты контекста сейчас применены.

1. **Если выбран текущий проект:**
   - Дай прямую ссылку на файл «Актуальный промпт.md» в корне текущего проекта на GitHub.
   - Сформируй ссылку по пути текущего проекта в репозитории `yeatu/obsidianGP`, ветка `main`.
   - Не открывай, не читай и не анализируй содержимое файла. Для выполнения команды достаточно сформировать ссылку.
   - Не перечисляй компоненты по содержимому проектного промпта.

2. **Если текущий проект не выбран:**
   - Сообщи, какой промпт личности применён, если он есть.
   - Сообщи, какой функциональный промпт применён, если он есть.
   - Сообщи, какие дополнительные инструкции применены, если они есть.
   - Для каждого применённого компонента укажи название и прямую ссылку на соответствующий исходный файл в GitHub.
   - Учитывай только фактически выбранные и загруженные компоненты. Наличие файла в каталоге промптов не означает, что он применён.
   - Не открывай и не перечисляй невыбранные файлы.

3. Если соответствующий компонент отсутствует, укажи, что он не применён. Не делай предположений и не выдавай доступные, но не загруженные файлы за активные.

4. Не изменяй «Актуальный промпт.md», исходные промпты, инструкции или другие файлы в ходе выполнения этой команды.
