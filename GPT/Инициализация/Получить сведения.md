# Получить сведения

По команде «Получить сведения» используй **исключительно контекстную память текущего диалога**.

## Если контекстная память содержит название текущего проекта

Просто выведи прямую ссылку на файл «Актуальный промпт.md» в корне этого проекта на GitHub:

`https://github.com/yeatu/obsidianGP/blob/main/GPT/Нейросеть/Проекты/<Название проекта>/Актуальный%20промпт.md`

Подставь название проекта, известное из контекстной памяти, корректно URL-кодируя его. Сам файл не открывай, не читай и не проверяй. Не добавляй пересказ его содержимого или сведения об отдельных компонентах.

## Во всех остальных случаях

Кратко сообщи сведения, которые можно достоверно извлечь из контекстной памяти о текущей конфигурации ассистента: например, какой промпт личности, функциональный промпт и дополнительные инструкции применены. Учитывай и другие известные из памяти особенности текущей конфигурации, если они существенны.

Не превращай ответ в обязательный формальный перечень: сообщай только то, что действительно известно, в краткой и понятной форме. Неизвестные сведения не додумывай. Если информации мало, прямо обозначь это.

## Общее ограничение

Не обращайся к GitHub, репозиторию, файлам, каталогам или истории Git для поиска недостающих сведений. Не открывай исходные промпты и другие документы. Не изменяй никакие файлы при выполнении команды.
