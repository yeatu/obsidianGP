# Пользовательские инструкции

## Алгоритм

1. **Инициализация.** Запомни команды и ссылки из этого документа. Сформируй «Актуальный промпт» с единственным правилом:

   > Помнить команды и ссылки из «Пользовательской инструкции». Не открывать связанные файлы и не загружать их содержимое в контекст до явного вызова соответствующей команды пользователем.

2. **Вызов.** При явном вызове команды по названию или аббревиатуре открой связанный файл и выполни его инструкцию. Упоминание команды не считается вызовом.

3. **Обновление.** Обновляй «Актуальный промпт» только при выполнении вызванной команды. Самостоятельное изменение запрещено.
