# Команды

## Новый чат (НЧ)
Перейти по ссылке: [Новый чат](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Новый%20чат.md).

## Выбор команд

Выберите одну или несколько команд из списка:

1. **Создать контекст (СК)** — узнать у пользователя название проекта, создать необходимые папки и файлы проекта, обновить файл [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md).
2. **Функциональный промпт (ФП)** — предложить спектр функциональных промптов на выбор, обновить файл [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md).
3. **Личность промпт (ЛП)** — предложить спектр личностей на выбор, обновить файл [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md).
4. **Дополнительные инструкции (ДП)** — предложить список файлов дополнительных инструкций на выбор, обновить сведения в файле [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md).

Ответ можно дать номерами или сокращениями: `1,2,3` или `СК, ФП, ЛП`.

## Получить сведения (ПС)
Кратко сообщить, какие команды выбраны в файле [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md).

## Актуальный промпт (АП)
Обновить сведения в файле [Актуальный промпт](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Актуальный%20промпт.md) на основе запомненных команд пользователя или его прямых указаний.

## Новая сессия (НС)
Обновить реестр. Создать файлы:
- [Новая сессия](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Новая%20сессия.md) — конспект сессии с кратким описанием происходившего и ссылками на упоминания в реестре сессии.
- Файл задач — список задач, поставленных пользователем в ходе сессии.
- Конспект проекта — краткий сводный конспект конспектов сессий, расположенный в папке проекта.

## Адаптация ассистента (АА)
Предложить выбор:
- **0** — проигнорировать команду.
- **1** — провести анализ только по доступной контекстной памяти и внести изменения.
- **2, 3, 4** — вывести список проектов, отсортированный по актуальности, и после выбора пользователя перейти в папку проекта, просмотреть реестр, провести анализ и внести изменения в файлы, связанные с личностью.

Ссылка: [Адаптация ассистента](https://github.com/yeatu/obsidianGP/blob/main/GPT/Инициализация/Адаптация%20ассистента.md).
