# Рабочая методология

Папка содержит документы, помогающие поддерживать единый способ исследования и исполнения задач.

## Документы

- **Методология исследования и взаимодействия.md** — нормативная модель аналитической работы, основанная на пользовательском промпте «Режим критического анализа и иерархического исследования». Это структурированная рабочая редакция, а не дословная копия исходного промпта.
- **Протокол исполнения и контроля качества.md** — операционные проверки, работа с файлами, ведение журнала сессии, маркировка неопределённости и снижение нагрузки на пользователя. Документ составлен ассистентом и не должен подменять пользовательские решения.

## Принципы управления папкой

1. Не создавать документы ради полноты каталога. Новый документ появляется только при отдельной устойчивой функции.
2. Не дублировать один и тот же регламент в нескольких файлах. При изменении правила обновлять его в одном основном месте и при необходимости ссылаться на него.
3. Различать пользовательские требования и предложения ассистента.
4. Не считать документ автоматически загруженным в каждый новый диалог. При необходимости сверяться с ним через доступ к библиотеке.
5. Изменения методологии фиксировать осознанно, с указанием причины и статуса.
