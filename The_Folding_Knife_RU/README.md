# The Folding Knife — рабочая структура перевода

Проект предназначен для подготовки русского перевода книги K. J. Parker.

## Структура

- `original/` — исходный EPUB и исходные фрагменты книги, разделённые по главам.
- `ru/` — соответствующие русские переводы глав.

Фрагменты в обеих папках должны иметь одинаковые номера и имена, чтобы их можно было сопоставить.

> Репозиторий сейчас публичный. Исходный текст книги и полный перевод не размещаются здесь до переноса проекта в приватный репозиторий или подтверждения права на публичное распространение.
