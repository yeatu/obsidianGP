# Русский перевод

Здесь будут храниться переводы соответствующих глав.

Имена и номера файлов должны совпадать с файлами из папки `original/`, например:

- `00-front-matter.ru.html`
- `01-chapter-one.ru.html`
- `02-chapter-two.ru.html`

Это позволит сверять каждую часть с оригиналом и позднее собрать переведённые главы в единый EPUB.

Полные тексты перевода будут добавлены после переноса проекта в приватный репозиторий или подтверждения права на публичное распространение.
