# История изменений

**Версия структуры:** 0.1  
**Назначение:** сохранять проверяемую историю изменений глобального профиля пользователя и основания для каждого изменения.

## Правила ведения

1. Каждое содержательное изменение «Актуальный профиль.md» получает отдельную запись.
2. Запись должна содержать дату, версию профиля до и после изменения, описание правки и основания.
3. Указываются ID наблюдений и ссылки на исходные реестры, если они существуют.
4. Отмечается, было ли изменение автоматическим по установленным правилам или подтверждено пользователем.
5. Не переписывать прошлые записи задним числом. Исправления оформлять отдельной записью.
6. Для отмены изменения создавать новую запись, ссылающуюся на исходную.
7. Не считать изменение завершённым, пока обновлённый профиль не перечитан и результат не проверен.
